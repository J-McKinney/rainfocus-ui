# jesse-mckinney-rf-ui

A React + Vite implementation of the RainFocus UI take-home project.

## Requirements

- [Node.js](https://nodejs.org/) 18+ (includes npm)

## Running in development mode

```bash
npm install
npm run dev
```

This starts the Vite dev server (with hot module reload) and prints a local URL — typically `http://localhost:5173` — to open in your browser.

## Building for production

```bash
npm install
npm run build
```

This compiles the app into a static `dist/` folder (with `index.html` as the entry point) that can be served by any static file host.

To preview the production build locally:

```bash
npm run preview
```

## Project structure

- `src/` — application source (components, hooks, styles, icons)
- `dist/` — production build output (generated by `npm run build`)
- `public/` — static assets copied as-is into the build

## Notes

The dark mode toggle, and a couple of additional hidden easter-egg toggles, live on the icon rail buttons in the sidebar — click around!
